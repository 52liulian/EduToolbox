2. 校对与编辑

每行一个词语；以 【组名】 开头的行是分组标题，可直接增删改； //拼音 开头的行为自动识别的“可能拼音行”，不会进入词语列表。

3. 导出

识别规则说明

  • 分组标题：包含「第X单元 / 第X课 / 语文园地 / 识字 / 口语交际 / 习作 / 快乐读书吧」的行；其下词语归入该组，其余归入「未分组」。
  • 按空格、制表符、顿号、逗号切分词语，自动过滤空串与纯标点；组内重复词语只保留第一次出现。
  • 不含汉字且长度小于 30 的行视为“可能的拼音行”，单独标注、不进入词语列表。
