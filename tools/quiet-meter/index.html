课堂安静值检测器介绍

工具介绍

课堂安静值检测器是一款专为班级自习、考试监考、图书馆等场景设计的在线环境噪音监测工具。它利用设备麦克风实时采集声音数据，通过智能算法将音量换算为 0-100 的「安静值」（数值越大表示越安静），并以圆环可视化与状态文字直观反馈。

工具不仅能实时反馈当前噪音水平，还会每 5 秒自动进行一次采样记录，生成历史记录列表，方便教师课后复盘班级纪律走势。

主要特点：

  • 实时可视化：圆环动态填充，绿→黄→红渐变实时反馈环境噪音。
  • 自动采样记录：每 5 秒自动计算平均分贝与安静值，写入历史记录列表。
  • 智能状态判定：自动判定「非常安静 / 较为安静 / 有些吵闹 / 非常吵闹」四档状态。
  • 数据导出功能：支持一键导出 CSV 检测记录表格，方便后续复盘分析。
  • 沉浸全屏模式：适配投影仪与大屏设备，全屏投影效果更佳。
  • 本地隐私保护：音频不上传服务器，全部在浏览器本地处理。

使用说明

1. 开启检测

首次使用时，浏览器会询问麦克风权限，请点击「允许」。点击顶部的「开始检测」按钮即可开始监测环境声音。

2. 调节设置

您可以根据环境底噪调整「灵敏度」和「警告阈值」。例如在较吵闹的环境下，可以适当调低阈值，使圆环更早进入警告色。

3. 全屏投影

点击「全屏」按钮进入沉浸模式，此时只有核心的安静值与状态提示，非常适合投影在黑板上作为无声的提醒。

4. 导出报告

检测结束后，点击「导出记录」按钮，即可下载一份包含时间点、平均分贝、最高分贝和状态的 CSV 表格文件。

常见问题解答

Q：为什么显示「浏览器不支持麦克风」？

A：请确保您使用的是 Chrome、Edge 或 Safari 等现代浏览器，并检查系统设置中是否允许浏览器访问麦克风；同时本工具必须在 https 或 file 协议下加载才能获取麦克风权限。

Q：导出的文件怎么打开？

A：导出的文件为 .csv 格式，可以直接使用 Excel、WPS 表格或记事本打开。

Q：数据会上传到服务器吗？

A：不会。所有的声音处理都在您的浏览器本地进行，音频数据不会上传，也不会被保存，请放心使用。
