# 随机抽签系统工具

一个免费、轻量、易用的线上抽签工具，支持自定义选项、预设模板、随机打乱等功能。

## 功能特点

- ✨ **自定义选项**：支持自由编辑抽签选项，每行一个选项
- 📥 **导入功能**：支持从 `.txt` 文件导入选项列表
- 🎯 **预设模板**：内置多种常用场景预设
  - 吃什么？
  - 做决定（是/否）
  - 团队分配
  - 真心话/大冒险
  - 家务分工
  - 健身部位
  - 数字(1-10)
  - 字母(A-Z)
  - 星期
  - 扑克牌(52张)
- 🎲 **随机打乱**：点击开始后自动随机打乱顺序
- 🎴 **翻牌动画**：精美的卡片翻转动画效果
- 🔓 **逐一揭晓**：点击卡片逐一揭晓结果
- 🚀 **全部揭晓**：一键揭晓所有结果
- 📱 **响应式设计**：支持桌面端和移动端

## 使用方法

1. **打开页面**：直接在浏览器中打开 `index.html`
2. **编辑选项**：在左侧文本框中输入抽签选项，每行一个
3. **选择预设**：或点击预设按钮快速加载常用选项
4. **开始抽签**：点击「开始抽签」按钮
5. **揭晓结果**：点击卡片逐一揭晓，或点击「全部揭晓」

## 技术实现

- 纯 HTML/CSS/JavaScript 实现，无需依赖
- 使用 CSS3 3D 变换实现翻牌效果
